每个 bundle 目录下有：

- `index.js`：格式化后的完整文件，全局搜索从这里开始。
- `modules/<hash>.js`：按 NEJ 模块声明切出的单独文件。
- `modules.json`：模块索引，含偏移、长度与模块内出现的关键符号。

查找某个接口由哪个模块实现：

```bash
rg -l "mocQuizRpcBean.saveDraftAnswers" .reverse/*/modules/
rg "\"hash\": \"<模块 hash>\"" .reverse/*/modules.json
```
