# ADR 0003：平台相互独立（状态、失败、停止都按平台）

- 状态：已采纳｜2026-10-21
- 关联：`packages/application/src/state.ts`、`round.ts`、扩展的 status 视图

## 背景

早期一家平台没登录会整轮 `return`，另一家连试都不试；状态是一份全局标记，
一家在跑会挡住另一家；失败留痕也只有一条，两家互相覆盖。

## 决定

- 运行状态按 `platformId` 分开存（`runningSince`/`heartbeatAt`/`lastFinishedAt`/`failure`）。
- 本轮认领、停止请求、失败留痕、进度卡全部按平台维度。
- 一家没登录只记它自己：全都没做成才回「未登录」；否则如实报已做成的部分。

## 后果

- 好处：两家的执行互不占用；失败呈现与清除各归各家；并发写由用例层串行化保证不丢更新。
- 代价：状态多一层键；界面必须按平台渲染（换端时也要按平台组织）。
- 验证：`round.test.ts` 的「两家平台在一轮里」一组，以及跨平台并发断言（认领与写串行）。
