# Study Pilot

一个浏览器扩展，在你**自己已登录**的慕课平台账号上整理课程待办、
提醒截止时间，并提供可选的作答辅助。

> **与任何学习平台均无关联。** 由个人开发并维护，不是官方产品，
> 也未获得任何平台的授权或认可。使用时请遵守所在平台的使用条款。

## 定位

**它是什么**

一个本地运行的课程管理辅助工具，核心作用是把「我还有什么没做」讲清楚。
平台把测验、作业、考试、互评分散在各章节里，逐门课翻一遍才知道还剩什么。
本工具把这些汇总到一处，标明每一项的状态、截止时间与下一步。

在此之上提供可选能力，按「会不会自己动」分两类：

- **自动的（后台任务）** —— 检查时自己完成的那些：提交测验、提交互评与自评。
  **默认全部关闭**，需要逐个手动开启
- **手动的（页面内的）** —— 你打开作答页才出现的面板与说明：
  按题库填充、评分依据展示。**默认开启**，但真正写平台的动作由你点

**它的边界**

- 只处理用户自己账号上尚未完成、且仍在有效期内的单元。
  已过截止的单元不做提交，因为平台已不接受
- 登录状态直接沿用浏览器，不保存账号密码，也不代为登录
- 不采集数据、不上报、没有服务端。全部数据存在浏览器本地
- 考试不作自动提交。它只有一次作答机会，这个动作留给用户自己

**它适合谁**

需要在多个课程之间跟进作业与互评进度、并希望减少重复操作的学生。

## 它做什么

**整理待办** — 把所选课程下未完成的单元测验、作业、考试、互评汇到一处，
标明每一项的截止时间与当前状态，点击直达对应页面。
已过截止的单独列出，保留三天后不再显示（历史可在设置页的单元明细查看）。

**桌面提醒** — 分两类，各自可以关闭：

- **作业截止提醒** — 临近截止时提前若干天告知，默认开启
- **自动完成提醒** — 后台替你做完之后说明做了哪些，默认开启

**辅助完成客观题** — 单元测验与客观题考试页出现一个面板，可按课程题库
一次性填好客观题，也可以在这个面板里提交。默认开启，提交要你自己点。

**辅助完成评分** — 单元作业进入互评期后，可按平台要求的份数提交互评，
也可以提交自评。两者是独立的两件事，各自开关。

**得分指导** — 单元作业与主观题考试的评分依据直接显示在题目下方，
取自平台的 `judgeDtos`，含图片。

默认值的分界线是**「会不会自己动」**：后台任务在检查时自己就做了，所以默认关闭；
页面内的功能只有你打开页面、动手点才会发生，所以默认开启。

**做不了的** — 单元作业的正文是主观题，没有可自动填写的答案；
考试通常只有一次作答机会，扩展不代点提交。这两类只会出现在待办里，
需要你自己处理。

## 什么时候动

浏览器启动时检查一次，运行期间按设置的间隔周期性检查，也可以随时手动执行。

检查本身不发请求：先读本地快照，判断值不值得拉最新数据。
拉取只发生在两种情况下——快照里有能自动完成的事项，
或者今天还没完整拉过。因此「每天至少一次」这条始终成立，
而周期检查只是让检查的机会变多。

打开扩展弹窗或设置页时会立即拉取一次，这样看到的是当前状态而非缓存。

## 安装

从 `dist/study-pilot/` 加载：

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择该目录

装好后点扩展图标 → 「更多」→ 登录账号 → 读取课程列表 → 勾选要参与任务的课程。

## 它不做什么

- **不采集任何数据。** 没有服务器，代码里没有任何指向平台之外的请求地址
- **不存储密码。** 只读浏览器里已有的登录凭证，用来以你的身份发请求
- **不修改平台上的任何东西**，除非你主动打开对应的提交类功能

详见 [隐私政策](PRIVACY.md)。

## 开发

```bash
pnpm install
pnpm dev          # 开发模式
pnpm build        # 构建到 apps/extension/.output/
pnpm package      # 构建并整理出可安装的目录与归档
pnpm test         # 单元测试
pnpm typecheck    # 类型检查
```

### 调试宿主必须是 Chrome for Testing

品牌版 Chrome 自 137 起移除了 `--load-extension`，且没有 CDP 的 `Extensions` 域，
无法加载也无法重载扩展。原因与替代做法见
[调试环境限制](docs/development.md)。

### 改完代码要重载扩展

`--load-extension` 不会重载已注册的扩展。改完构建产物后必须跑：

```bash
node scripts/probe/run/reload-ext.mjs
```

否则测的还是旧版本 —— 这个坑不吃一次很难想到。

### 改完要自证

仓库带一套自检脚本，每条都是实测而非静态检查：

```bash
node scripts/probe/checks/selfcheck.mjs            # 后台接口与界面是否对得上
node scripts/probe/checks/check-classes.mjs        # 用到的类名是否都有样式
node scripts/probe/checks/check-copy.mjs           # 文案是否与功能一致
node scripts/probe/checks/check-toc.mjs            # 左侧导航与分区是否对得上
node scripts/probe/checks/check-control-styles.mjs # 按钮与链接的尺寸是否一致
node scripts/probe/checks/dryrun-tasks.mjs         # 打印会做什么，不执行
```

工具链的完整说明见 [scripts/probe/README.md](scripts/probe/README.md)。
